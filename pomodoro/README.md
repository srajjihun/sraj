# 월야(月夜) 뽀모도로

화면 **우측 상단**에 떠서 **모든 창 맨 앞**에 머무는 작은 뽀모도로 타이머.
먹빛 바탕에 금박 선묘 — 달·구름·물마루로 짠 배경화면 톤에 맞춘 위젯입니다.

## 실행 (개발용)

```bash
cd pomodoro
npm install
npm start
```

Electron 앱이라 macOS · Windows · Linux에서 모두 돕니다.

## Windows에서 더블클릭용 exe 만들기

터미널을 매번 켜지 않고 아이콘 더블클릭으로 쓰고 싶다면, **Windows 컴퓨터에서 딱 한 번만** 아래를 실행하세요.

```bash
cd pomodoro
npm install
npm run dist
```

끝나면 `pomodoro/dist` 폴더에 두 가지가 생깁니다.

- **`월야 뽀모도로 Setup x.x.x.exe`** — 설치형. 실행하면 시작 메뉴 · 바탕화면 바로가기가 생기고, 이후엔 그 아이콘만 누르면 됩니다. (추천)
- **`월야 뽀모도로 x.x.x.exe`** (portable) — 설치 없이 파일 하나로 바로 실행. USB에 담아 다녀도 됩니다.

설치형으로 켠 뒤에는 **트레이 아이콘 우클릭 → "로그인 시 자동 시작"** 을 체크해두면 컴퓨터 켤 때마다 자동으로 트레이에 떠 있습니다(창은 숨긴 채로 시작하고, 트레이 아이콘을 눌러 열면 됩니다).

> `npm run dist`는 이 리눅스 개발 환경(클라우드 세션)에서는 실행할 수 없습니다 — Windows용 exe를 만들려면 wine이라는 도구가 필요한데 여기엔 없어서, 실제 exe는 사용자님의 Windows 컴퓨터에서 만들어야 합니다. Node.js(https://nodejs.org)만 설치되어 있으면 됩니다.

## 기능

| | |
|---|---|
| **항상 맨 앞** | 상단 압정 아이콘으로 켜고 끔. macOS에서는 전체화면 앱 위에도 올라옵니다 (`screen-saver` 레벨) |
| **우측 상단 배치** | 처음 실행하면 주 모니터 우측 상단에 뜹니다. 아무 데나 끌어서 옮기면 그 자리를 기억합니다 |
| **집중 · 휴식 자동 진행** | 집중 25분 → 짧은 휴식 5분, 네 번째 집중 뒤에는 긴 휴식 15분. 구간이 끝나면 알아서 다음 구간으로 넘어갑니다 |
| **알림** | 구간이 바뀔 때 종소리(합성음) + 시스템 알림. 창이 가려져 있어도 잠깐 앞으로 끌어올립니다 |
| **시간 조절** | 톱니 아이콘 → 집중 / 짧은 휴식 / 긴 휴식 길이를 분 단위로 조절. 설정은 저장됩니다 |
| **트레이 상주** | `−` 버튼으로 숨기고 트레이(메뉴 막대) 아이콘으로 다시 꺼냅니다 |

### 단축키

| 키 | 동작 |
|---|---|
| `Space` | 시작 / 일시정지 |
| `R` | 초기화 |
| `Esc` | 설정 닫기 |

## 화면

- **집중** — 따뜻한 금빛. 진행 고리가 시계 방향으로 차오릅니다
- **휴식** — 달빛 상아색으로 전환되어 한눈에 구분됩니다
- 다이얼 가운데는 구름이 가로지르는 달, 아래는 흐르는 물마루 (타이머가 도는 동안에만 움직입니다)
- 달 아래 점 네 개는 긴 휴식까지 남은 집중 횟수

## 구성

```
pomodoro/
├── main.js              창 생성 · 항상 맨 앞 · 트레이 · 설정 저장
├── preload.js           contextBridge로 노출하는 최소 API
├── renderer/index.html  화면 전체 (CSS · SVG · 타이머 로직)
├── scripts/make-icon.js 트레이 아이콘(금빛 보름달) 생성
└── assets/tray.png      생성된 아이콘
```

타이머는 남은 시간을 깎아내리지 않고 **종료 시각과 현재 시각의 차이**로 계산합니다.
절전 모드에 들어갔다 나와도 시간이 밀리지 않습니다.

아이콘을 다시 만들려면 `npm run icon`.

## 참고

- **Windows** — 다른 "항상 위" 창(작업 관리자 등)에는 가려질 수 있습니다
- **macOS** — 위젯처럼 쓰라고 독 아이콘을 숨겼습니다. 종료는 트레이 메뉴 또는 설정 패널의 `종료`
- **Linux** — 창 투명도와 항상 위 동작은 창 관리자(compositor)에 따라 다를 수 있습니다
